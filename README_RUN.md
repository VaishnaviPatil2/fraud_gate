# Execution Guide: Evidence-Gated Risk-Aware Fraud Prevention, Detection and Recovery

This repository implements the M.Tech dissertation framework:
**"Evidence-Gated Risk-Aware Fraud Prevention, Detection and Recovery for Digital Payment Systems"**

---

## 1. Environment Setup (PowerShell on Windows 11)

### Step 1: Open PowerShell and set execution policy (if script execution is blocked)
```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

### Step 2: Create Python 3.12 Virtual Environment
```powershell
py -3.12 -m venv .venv
```

### Step 3: Activate the Virtual Environment
```powershell
.venv\Scripts\Activate.ps1
```

### Step 4: Install Dependencies
```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

---

## 2. Hardware Constraints & Execution Rules

- **RAM Constraint**: 8 GB RAM (~6 GB usable). Vectorized pandas with memory-efficient dtypes (`float32`, category/integer codes) and Parquet files are used throughout.
- **CPU Constraint**: 2 CPU cores. All parallel operations are restricted to `n_jobs <= 2`.
- **Windows Multiprocessing**: All execution scripts wrap entry points in `if __name__ == "__main__":`.
- **Modes**:
  - `--mode sample`: Default mode for development, unit testing, and pipeline verification (fast, subsampled).
  - `--mode full`: Full dataset evaluation. **Run only when explicitly specified.**

---

## 3. Running Experiments

### Running Master Orchestration
```powershell
# Run in default sample mode
python run_all.py --mode sample

# Run full dataset pipeline (only when explicitly instructed)
python run_all.py --mode full
```

### Running Individual Experiments
Each experiment module inside `exp/` can be executed independently via Python:
```powershell
# Run a specific experiment in sample mode
python -m exp.exp01_baseline --mode sample

# Run unit tests
pytest tests/
```

---

## 4. Output Directories
- `data/raw/`: Raw datasets (PaySim and IEEE-CIS).
- `data/processed/`: Processed temporal parquet files and cached feature matrices.
- `results/`: CSV output files containing raw numeric experimental results.
- `figures/`: Rendered evaluation charts and distributions.
- `logs/`: Execution logs generated by scripts and experiments.
